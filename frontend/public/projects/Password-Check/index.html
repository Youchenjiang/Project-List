密碼強度分析

為什麼安全且準確？

隱私保護：本工具使用 HIBP (Have I Been Pwned) API 的 k-匿名查詢模型，僅傳送密碼 SHA-1 雜湊值的前5碼到伺服器。您的完整密碼和完整雜湊值永遠不會離開您的裝置。

準確性保證：雖然只傳送前5碼，但伺服器會回傳數百個相關雜湊後綴，本工具在本地比對完整的40碼雜湊值，確保100%準確匹配。SHA-1雜湊碰撞機率極低（約2^-140），可確保結果可靠。

工作原理：

  1. 本地計算密碼的 SHA-1 雜湊值（40個十六進位字符）
  2. 僅傳送前5碼到 HIBP 伺服器
  3. 伺服器回傳所有以這5碼開頭的雜湊後綴清單
  4. 本地比對剩餘35碼，找到完全匹配的項目

原始程式碼基於 黑暗執行緒部落格 的 PowerShell 版本。

硬體破解速率來源

  • CPU 數據：基於 Hashcat 基準測試和公開測試報告
  • 消費級 GPU：參考 RTX 5090 官方規格和 SHA-1 破解基準
  • 資料中心 GPU：基於 NVIDIA B200 (Blackwell 架構) 的理論算力估算
  • ASIC 數據：基於 Antminer S19 Pro 的實際 SHA-256 算力轉換估算
  • 叢集數據：基於多個高階 GPU 並行計算的理論值

註：B200 為目前最強的資料中心 GPU (2025年)，實際破解速度會因硬體配置、溫度、軟體優化等因素而有所差異。
